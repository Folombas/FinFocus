## Налоги
- НПД (самозанятость): 4% - платежи физлиц, 6% - юрлиц, лимит 2,4 млн ₽/год (справка 422-ФЗ; проверить текущие лимиты на ФНС).
- ИП на УСН «доходы»: 6% + страховые взносы.
- НДФЛ физлица: 13% / 15% при высоких доходах.
- Донаты по своей природе - доход, с которого нужно заплатить налог; разъяснения ФНС (проверить письмо Минфина перед публикацией).
- Источник-старт: https://www.nalog.gov.ru/ (сервисы ФНС: «Самозанятые», ИП).
