# FinFocus 💰

**FinFocus** — это обучающий сайт о личных финансах для обычных людей, а не для инвесторов. Никаких сложных таблиц, громких обещаний и «стратегий пассивного дохода» — только простые и понятные правила: как вести бюджет, откладывать без срывов, ловить честные скидки и не переплачивать банкам.

🌐 **Живая версия:** [folombas.github.io/FinFocus](https://folombas.github.io/FinFocus/)

## 📄 Страницы

| Страница | Файл | Что внутри |
| --- | --- | --- |
| 🏠 Главная | `index.html` | Карточки-входы во все разделы |
| 📊 Бюджет | `budget.html` | Правило 50/30/20, учёт трат, подушка безопасности |
| 🏦 Накопления | `savings.html` | Калькулятор «тихих побед», стратегии (конверты, автосписание, округление), чек-лист |

| 🎓 Финансовая грамотность | `finlit.html` | Калькулятор инфляции, мини-словарь, база безопасности и защита от мошенников |
| ☕ Привычки экономии | `habits.html` | Термос вместо кофейни, домашние обеды, правило 24 часов |
| 🏦 Долги и кредиты | `loans.html` | Аннуитетный калькулятор переплаты, три правила кредита, чек-лист долгового здоровья |
| 🚲 Велосипед vs Авто | `bicycle.html` | Философия проекта: экономия, экология и здоровье |

## 🧰 Как устроен проект

- **Чистый HTML / CSS / JavaScript** — без фреймворков, сборки и зависимостей. Открывать можно прямо из папки.
- Все интерактивные элементы (4 калькулятора на ползунках, вкладки, FAQ-аккордеоны, чек-листы, анимации при скролле) живут в одном файле `main.js`.
- Единая тёмная тема и стили — в `style.css`.

## 🚀 Запуск локально

Достаточно открыть `index.html` в браузере. Если нужен локальный сервер:

```bash
npx serve .
```

## 📦 Деплой

Сайт публикуется автоматически через **GitHub Pages** из ветки `main`: любой коммит попадает на [folombas.github.io/FinFocus](https://folombas.github.io/FinFocus/) через минуту-другую.
