# FinFocus 💰

**FinFocus** — это обучающий сайт о личных финансах для обычных людей, а не для инвесторов. Никаких сложных таблиц, громких обещаний и «стратегий пассивного дохода» — только простые и понятные правила: как вести бюджет, откладывать без срывов, ловить честные скидки и не переплачивать банкам.

🌐 **Живая версия:** [folombas.github.io/FinFocus](https://folombas.github.io/FinFocus/)

🏭 [Конвейер](AI-CONVEYOR.md) — контракт для ИИ-ассистентов, работающих с репозиторием.

## Локальная проверка

Сборка не нужна: открой `index.html` в браузере или подними любой статический сервер:

```bash
python3 -m http.server 8000
# затем открой http://localhost:8000
```

Быстрые проверки без линтера:

```bash
# Синтаксис всех JS-файлов
for f in js/*.js; do node --check "$f"; done

# В каждом HTML ровно один <body> и не больше одного <header>
for f in ./**/*.html; do echo "$f: body=$(grep -c '<body' "$f") header=$(grep -c '<header' "$f")"; done
```

## CI

[`.github/workflows/ci.yml`](.github/workflows/ci.yml) на каждый push и PR запускает:

1. `node --check` для всех JS-файлов в `js/` — синтаксическая чистота;
2. структурную проверку HTML: в каждом файле ровно один `<body>` и не больше одного `<header>`.

Статус прогонов виден на вкладке **Actions** репозитория.

## SEO

На всех индексируемых страницах есть `rel="canonical"` и Open Graph-теги, карта сайта — в `sitemap.xml`. Страница 404 закрыта `noindex` и использует абсолютные пути, чтобы не ломаться на глубоких URL GitHub Pages.
